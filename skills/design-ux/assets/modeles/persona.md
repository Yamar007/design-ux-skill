> « [Une phrase dite par une personne interrogée, ou marquée (imaginée)] »

## Profil

| | |
|---|---|
| **Objectifs** | Ce qu'il ou elle cherche à accomplir |
| **Motivations** | Pourquoi |
| **Influences** | Ce qui inspire ou oriente ses décisions |
| **Besoins** | Ce qu'il lui faut pour atteindre ses objectifs |
| **Souhaits** | Ce qu'il ou elle voudrait en plus, ou à la place |
| **Problèmes** | Ce qui gêne, frustre, fait abandonner |

## Contexte

| | |
|---|---|
| **Activité** | Les tâches effectuées |
| **Lieux** | Où (bâtiment, pièce, transport) |
| **Moments** | Quand, combien de temps, à quelle fréquence |
| **Personnes** | Qui est présent ou impliqué |
| **Objets** | Outils, appareils, documents utilisés |
| **Services** | Services utilisés, de la marque ou non |

- **Facilités** : ce sur quoi on peut compter (compétences, habitudes).
- **Difficultés** : ce qu'il faut éviter de lui demander.
